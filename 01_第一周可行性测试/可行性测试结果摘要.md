# 第一周可行性测试结果摘要

生成日期：2026-10-06

## 1. 本次测试做了什么

使用 Binance USDT 永续合约公开 REST API，下载 BTCUSDT 和 ETHUSDT 最近约 180 天的：

- 历史资金费率结算记录；
- 1 分钟永续合约收盘价。

基于事件窗口 `[-120, +120]` 分钟，生成三组事件路径：

- A：真实资金费率结算；
- B：真实结算时间之后半个结算周期的伪事件；
- C：真实结算且绝对资金费率不超过 `0.001%` 的近零费率事件。

注意：本次 API 返回的是**历史实现资金费率**，不是已核验的结算前预测费率。因此本次结果只用于探索性可行性判断，不支持“预期资金支付造成价格压力”的因果结论。

## 3. 初步数字结果

累计价格变化以事件前 `-10` 至 `-1` 分钟价格中位数为基准：

| 事件组 | tau=-60 | tau=0 | tau=+60 |
|---|---:|---:|---:|
| A 真实结算 | -2.05 bp | 0.28 bp | 2.42 bp |
| B 伪结算 | -3.32 bp | -0.47 bp | 1.88 bp |
| C 近零费率 | 4.87 bp | 0.36 bp | 2.38 bp |

绝对费率分位数的探索性结果：

- 最低四分位在 `tau=+60` 的平均累计变化约 `1.21 bp`；
- 最高四分位约 `5.63 bp`；
- 但 95% 置信区间仍较宽，最高分位区间约为 `[-0.29, 11.55] bp`，不能作为显著的剂量反应证据。

## 4. 可行性判断

### 支持继续的部分

1. 数据管道能够稳定取得 180 天、两个主流合约的资金费率和分钟价格；
2. 每个主合约约 540 个结算事件，满足第一轮事件图测试的样本规模；
3. 真实事件、伪事件和近零费率组都能形成有效窗口；
4. 最高费率分位数在结算后 60 分钟的点估计较大，值得用更严格的识别设计继续检查。

### 当前不能支持的结论

1. A 与 B 的路径总体高度重叠，尚未显示清晰的结算独有效应；
2. C 组在结算前波动较大，说明“近零费率”不是天然的同状态反事实；
3. 只有永续收盘价，无法区分现货共同冲击、永续微观结构噪声和真正的价格压力；
4. 使用 realized funding 不能检验结算前预期支付机制；
5. 当前置信区间是事件独立的近似区间，尚未按事件时间、日期和合约聚类。

## 5. 下一步优先级

1. 核验 Binance、Bybit、OKX 哪个平台能取得结算前历史预测费率或可重建的 premium index；
2. 加入现货/指数价格，重新计算 perp-index basis；
3. 加入结算前 OI、成交量、盘口深度和价差；
4. 使用同一结算时点的横截面费率剂量回归，而不是只比较三条平均路径；
5. 将真实费率事件与多个伪事件、同日随机时点进行比较；
6. 只在使用结算前可观测处理变量后，才把论文定位为机制性因果研究。

## 5A. 第一周扩展诊断

### 正负费率

- 正费率事件在结算后 60 分钟的平均累计变化约为 `2.79 bp`，95% 区间约为 `[-0.14, 5.73] bp`；
- 负费率事件约为 `1.04 bp`，95% 区间约为 `[-4.79, 6.87] bp`；
- 点估计方向符合“正费率事件更容易出现结算后上行”的探索性现象，但区间仍包含 0，不能据此确认方向机制。

### 结算前 OI 状态（仅 BTCUSDT，使用已有 5 分钟 OI 数据）

- OI 中高和 OI 最高组在结算后 60 分钟的点估计约为 `6.28-6.33 bp`；
- OI 最低和中低组分别约为 `-3.09 bp` 和 `-2.42 bp`；
- 这是目前最有价值的机制线索，但置信区间很宽，且 OI 数据与本次价格数据的覆盖期并不完全一致，必须在正式模型中重新对齐并聚类。

### 真实减伪事件的简单差异

真实组减伪事件组的累计变化差异为：

- `tau=0`：约 `0.75 bp`，95% 区间约为 `[-0.07, 1.57] bp`；
- `tau=+60`：约 `0.54 bp`，95% 区间约为 `[-3.37, 4.46] bp`。

这说明真实结算路径尚未明显脱离日内时点模式；高 OI/费率分组的信号可能比单纯的事件虚拟变量更值得研究。

## 6. 第一周止损判断

本次结果的结论是：**数据和编程可行，结算效应的识别尚未通过。**

因此不停止题目，但不应直接进入完整论文写作。下一阶段的硬门槛是：拿到结算前可观测的预测费率，或明确改写为描述性结算时序响应研究。
