# 第五周：事件分钟定位敏感性结果摘要

生成日期：2026-10-06

## 1. 目的

第一周将资金费率时间戳和 1 分钟价格统一向下取整到分钟。第一周面板已经有
`tau=-1/0/+1`，但那只是相对事件路径，并不能回答：如果事件标记因时间戳
解析、交易所记录延迟或分钟边界误差而落在相邻分钟，结论是否会改变。

本周将每个事件标记分别平移 `-1`、`0`、`+1` 分钟，使用同一套 1 分钟永续
价格和事件前 `[-10,-1]` 分钟中位数基准，重新计算 `tau=-1/0/+1/+5/+60/+120`
累计价格变化。真实事件和伪事件差异使用 UTC 日期聚类 bootstrap（4,000 次）。

## 2. 样本和复现规则

- 数据：第一周 `data/perp_1m.csv` 与 `output/事件索引.csv`；
- 样本：仅保留第一周完整 `[-120,+120]` 事件面板中的有效 `event_id`，因此不因本周局部窗口重新纳入边界事件；
- 有效事件：2,273 个，其中真实结算 1,078 个、伪结算 1,080 个、近零费率 115 个；
- 每个事件有 3 个标记版本，最终事件级面板 6,819 行；
- 价格缺口规则与第一周相同：分钟重采样后最多前向填充 1 分钟；
- 重要限制：本分析只检验事件时间定位的敏感性，不能把 realized funding 解释为预测费率，也不能独立建立因果识别。

样本排除记录见 `data/第五周与第一周样本审计_排除事件.csv`。本次排除的是第一周完整窗口已判定无效的两个最早真实事件。

## 3. 复核第一周面板

平移 `0` 分钟时，本脚本与第一周面板的数值误差仅为浮点舍入误差：

| 原始 tau | 匹配事件 | 最大绝对差异（bp） |
|---:|---:|---:|
| -1 | 2,273 | < 8e-15 |
| 0 | 2,273 | < 8e-15 |
| +1 | 2,273 | < 8e-15 |

这确认敏感性脚本没有改变第一周的价格重采样、基准价格或收益定义。

## 4. 真实减伪差异（日期聚类 bootstrap）

下表列出最直接的分钟定位结果。`marker_shift_min` 是相对第一周事件时间的
平移，`car_+0` 是定位后的结算时点累计变化，`local_jump_m1_to_0` 是定位
前一分钟到定位时点的局部跳跃。

| 平移 | 结果 | 差异（bp） | 95% CI（bp） | ±1 bp 等价 |
|---:|---|---:|---:|---|
| -1 | car tau=0 | 0.307 | [-0.603, 1.235] | 否 |
| 0 | car tau=0 | 0.754 | [-0.254, 1.787] | 否 |
| +1 | car tau=0 | 0.152 | [-1.041, 1.360] | 否 |
| -1 | 局部跳跃 -1→0 | 0.416 | [-0.024, 0.845] | 是 |
| 0 | 局部跳跃 -1→0 | 0.513 | [-0.298, 1.325] | 否 |
| +1 | 局部跳跃 -1→0 | -0.470 | [-1.291, 0.317] | 否 |

结算后 60 分钟的真实减伪差异在三种定位下分别为约 `0.57`、`0.58`、`0.27`
bp，置信区间均较宽且跨越零。完整结果见
`output/第五周分钟定位敏感性_真实减伪_日期聚类bootstrap.csv`。

## 5. 解释和下一步

1. **点估计对 ±1 分钟定位有变化，但没有方向稳定的跳跃。** 原始定位下 tau=0 的点估计约 `0.75 bp`；向前/向后移动一分钟后约为 `0.31/0.15 bp`。这说明单分钟价格噪声会影响点估计，不宜把一个分钟的局部跳跃直接写成结算冲击。
2. **分钟定位不是当前结论的主要瓶颈。** 三种定位下结算后 60 分钟结果都没有形成稳定显著差异；主要问题仍是效应精度、预测费率历史面板和机制变量不足。
3. **正式论文应预先声明定位规则。** 主规格可保留交易所时间戳向下取整；将 `-1/+1` 分钟作为预注册的时间定位敏感性，并报告日期聚类或 block/wild bootstrap 区间。
4. **不要只报告 tau=0。** 建议同时给出 `tau=-1,0,+1` 和局部收益 `-1→0`，并将 `±1 bp` 等价区间作为描述性精度指标，而不是无效效应证明。
