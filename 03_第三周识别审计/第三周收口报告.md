# 第三周识别审计收口报告

生成日期：2026-10-06  
研究题目工作名：资金费率结算、拥挤交易与加密永续合约短期价格压力

## 一、第三周完成的工作

本周的目标不是根据 `p > 0.05` 直接宣布“没有效应”，而是检查当前设计能否把价格效应识别到具有经济意义的精度，并审计结算前费率代理变量的质量。

已完成：

1. 对真实结算事件与伪结算事件重新计算 `tau=-60、0、+60、+120` 的价格累计变化差异；
2. 报告差异的 95% 置信区间和 80% 功效下的最小可检测效应（MDE）；
3. 对永续—现货、永续—指数基差计算结算前到结算时点及结算后 60 分钟的变化；
4. 用严格滞后的 premium-index 信息构造 `reconstructed_pre_funding_proxy`，并与已实现 funding 做测量误差审计；
5. 对第三周脚本进行一次完整复现运行，输出与原结果一致。
6. 追加按 UTC 日期的 4,000 次 cluster bootstrap，并补充基差 `tau=-1 -> 0` 的局部跳跃指标。

复现脚本：`第三周识别审计.py`  
核心输出：

- `output/第三周价格效应精度与等价性.csv`
- `output/第三周基差效应精度.csv`
- `output/第三周费率代理测量审计.csv`
- `output/第三周_效应精度与等价区间.png`
- `output/第三周价格效应_日期聚类bootstrap.csv`
- `output/第三周基差效应_日期聚类bootstrap与局部跳跃.csv`

## 二、样本和估计对象

- 资产：Binance BTCUSDT、ETHUSDT 永续合约；
- 价格频率：1 分钟；
- 主要事件窗口：`[-120,+120]` 分钟；
- 真实事件：1,080 个；进入价格差异估计的完整事件为 1,078 个；
- 伪事件：1,080 个；进入价格差异估计的完整事件为 1,080 个；
- 基差完整事件：268 个，因现货、指数和标记价格仅覆盖最近约 45 天；
- 当前区间仍为未聚类的诊断区间，尚未作为最终论文标准误。

价格主估计量为：

```text
真实事件平均累计价格变化 - 伪事件平均累计价格变化
```

基差估计量为每个事件相对于 `tau=-10` 的变化：

```text
basis(tau=0 或 +60) - basis(tau=-10)
```

## 三、价格效应精度

| 结果变量 | 差异（bp） | 95% CI（bp） | MDE80（bp） | ±1 bp 等价 |
|---|---:|---:|---:|---|
| `tau=-60` | 1.264 | [-2.437, 4.964] | 5.286 | 否 |
| `tau=0` | 0.754 | [-0.067, 1.575] | 1.173 | 否 |
| `tau=+60` | 0.544 | [-3.368, 4.456] | 5.589 | 否 |
| `tau=+120` | 1.195 | [-4.762, 7.151] | 8.510 | 否 |

解释：结算时点 `tau=0` 的点估计不到 1 bp，且 95% 区间已经落入 ±2 bp，但尚未落入预设的 ±1 bp 经济等价区间。其余时间点的区间较宽，无法排除具有经济意义的价格效应。

因此目前只能说：

> 现有样本没有发现清晰的结算时点价格跳跃，但价格效应的统计精度不足，不能把“不显著”写成“因果效应为零”。

### 日期聚类稳健性复核

将 UTC 日期作为 cluster、进行 4,000 次 cluster bootstrap 后，价格区间变宽：

| 结果变量 | 点估计（bp） | 日期聚类 bootstrap 95% CI（bp） | MDE80（bp） |
|---|---:|---:|---:|
| `tau=-60` | 1.264 | [-4.166, 6.644] | 7.649 |
| `tau=0` | 0.754 | [-0.245, 1.816] | 1.481 |
| `tau=+60` | 0.544 | [-4.962, 5.876] | 7.687 |
| `tau=+120` | 1.195 | [-6.561, 9.195] | 11.311 |

这一步进一步确认：结算时点点估计较小，但尚未达到 ±1 bp 的等价识别标准；把事件视为独立观测会低估不确定性。

## 四、基差机制证据

| 基差指标 | 结果 | 平均变化（bp） | 95% CI（bp） | MDE80（bp） | ±1 bp 等价 |
|---|---|---:|---:|---:|---|
| 永续—现货 | `-10 -> 0` | 0.096 | [-0.006, 0.198] | 0.146 | 是 |
| 永续—现货 | `-10 -> +60` | 0.166 | [0.043, 0.288] | 0.175 | 是 |
| 永续—指数 | `-10 -> 0` | 0.051 | [-0.170, 0.273] | 0.316 | 是 |
| 永续—指数 | `-10 -> +60` | 0.031 | [-0.215, 0.276] | 0.351 | 是 |

基差点估计很小，且日期聚类 bootstrap 区间均落入 ±1 bp。这支持一个可继续检验的机制假设：预期资金支付可能通过结算前的基差调整被提前吸收，而不是在结算瞬间形成独立价格冲击。

需要区分两个结果变量：`basis(0)-basis(-10)` 是局部水平变化，不等于结算断点；更接近“瞬时跳跃”的 `basis(0)-basis(-1)` 为：永续—现货 0.069 bp，95% CI [-0.049, 0.186]；永续—指数 0.055 bp，95% CI [-0.231, 0.341]。这些结果仍属于事件描述和稳健性诊断，不能单独构成因果识别。

但这里仍有两个限制：

1. 区间尚未按事件时间、交易日或资产进行聚类，也未用 block/wild bootstrap；
2. 日期 bootstrap 只是单向 cluster 的稳健性检查，正式论文仍应比较 symbol×date 聚类、block/wild bootstrap 或事件级随机化推断；
3. 45 天子样本可能存在市场状态选择，不能直接代表 180 天价格事件样本；
4. 真实事件的伪事件目前固定为结算后 4 小时，可能混入日内时段差异；尚未完成同日同小时随机 placebo 或真实事件—伪事件 DiD；
5. funding 时间和 1 分钟 K 线均被取整到分钟，实际事件与价格观测可能存在最多约 1 分钟的定位误差，尚未完成 `tau=-1/0/+1` 的时间敏感性。

## 五、结算前费率代理变量审计

代理变量定义为：

```text
过去 8 小时 premium-index 均值 + 利息项，再按费率上下限截断
```

所有计算使用结算前信息，避免把结算时点之后的 premium 倒灌进处理变量。该变量明确是 `reconstructed_pre_funding_proxy`，不是交易所历史保存的预测费率。

| 合约 | 事件数 | 覆盖率 | 与 realized funding 相关系数 | MAE（bp） |
|---|---:|---:|---:|---:|
| BTCUSDT | 540 | 24.8% | 0.580 | 3.819 |
| ETHUSDT | 540 | 24.8% | 0.833 | 3.901 |

代理与实现费率有信息关联，但约 3.8--3.9 bp 的平均绝对误差不可忽略，且覆盖率只有 24.8%。因此不能用该代理直接替代历史预测费率作为最终主解释变量。

## 六、第三周的可支持结论

### 可以支持

- Binance BTC/ETH 永续合约的资金结算事件、价格、现货、指数和标记价格数据管道可以运行；
- 当前样本没有显示出清晰、稳定的结算瞬时价格跳跃；
- 基差结算前后的变化很小，初步与“预期提前吸收”机制一致；
- premium-index 历史信息能够构造一个透明的结算前费率代理，但存在明显测量误差和覆盖不足。

### 目前不能支持

- 不能宣称资金结算没有因果价格效应；
- 不能把已实现 funding 当作结算前可观测的预测费率；
- 不能把未聚类的置信区间作为正式论文的最终推断；
- 不能把单向日期 bootstrap 视为最终的聚类或随机化推断；
- 不能仅凭当前结果宣称订单流、持仓或流动性是中介机制，因为这些机制变量尚未进入同一识别框架。

## 七、第三周决策

**结论：第三周通过“数据与识别诊断完成”门槛，但未通过“正式因果识别完成”或“直接写完整因果论文”门槛。**

建议的工作标题从“结算造成短期价格压力”收窄为：

> 资金支付预期是否在结算前被永续合约市场吸收？来自基差、持仓与流动性状态的证据

这不是放弃原问题，而是把可识别对象从“结算动作本身”改成“可预期结算的事前吸收与结算时点剩余冲击”。

## 八、第四周入口和止损标准

第四周只需要完成一个识别升级，不应无止境扩张：

1. 持续归档 OKX 或 Bybit 的 `nextFundingRate`，形成多个结算周期的真正结算前预测费率；
2. 将价格和基差结果改为事件时间/日期聚类，或使用 block bootstrap；
3. 在同一事件面板中加入 OI、价差、盘口深度或订单流中的至少一种变量；
4. 重新计算异质性和等价性区间。
5. 用同日同小时 placebo 或真实事件—伪事件 DiD 检查固定 `+4h` 伪事件设计，并做 `tau=-1/0/+1` 的分钟定位敏感性。

第四周结束时按以下规则决策：

| 结果 | 决策 |
|---|---|
| 有预测费率，且高 OI/低深度状态出现机制异质性 | 继续完整论文 |
| 结算时点仍无独立冲击，但事前 basis/OI/流动性吸收稳定 | 改写为“预期资金支付的提前吸收”论文 |
| 只有 realized funding、价格和宽区间，没有机制变量 | 暂停原题，转向邻近的市场微观结构问题 |

## 九、研究诚信声明

本报告中的价格和基差区间是探索性诊断结果，不是已完成的因果识别结果。最终论文必须补充历史预测费率、聚类或 bootstrap 推断、机制变量和制度规则分段，并在报告中同时给出效应量、置信区间、MDE 和经济等价区间。
